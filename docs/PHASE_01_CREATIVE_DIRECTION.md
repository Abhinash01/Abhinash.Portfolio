## 4. The Polar Star: What to Avoid

To maintain our uncompromising creative standards, the following anti-patterns are strictly forbidden:
- **No Generic "Cyberpunk / Dark Terminal" Tropes:** No green matrix code rain, no gratuitous dark neon glows, no synthetic retro-wave grids.
- **No Off-the-Shelf SaaS Template Aesthetics:** No bubbly purple CTA buttons, generic SVG doodles, or cookie-cutter card grids with generic stock icons.
- **No Uncontrolled 3D Gimmicks:** The 3D scene is not a toy; it is an ambient, responsive visual anchor. No low-poly unshaded models, no laggy full-screen canvas models that choke mobile GPUs.
- **No Excessive Glassmorphism:** Frosted glass is restricted strictly to the floating navbar. Content cards must use solid opaque `#FFFFFF` surfaces with 1px borders.
- **No Obstructed Usability:** The 3D canvas must never block text selection or button interactions (`pointer-events: none` on canvas wrapper; text on `z-index: 10`).
- **No Placeholder Artistry:** Every visual artifact, diagram, and render must be bespoke, crisp, and directly related to Abhinash's actual work.
- **No Superficial Over-Animation:** Animations must never obstruct user intent. If an animation delays access to a project link or text content by more than 400ms, it must be refined.
